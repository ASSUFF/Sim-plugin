# 发给 WorkBuddy 里 DeepSeek 的 HFSS 验收提示词

把下面分隔线之间的正文整段复制到 WorkBuddy。工作区请打开插件根目录，也就是含有 `pyproject.toml` 的目录。

---

你在本机验收 HFSS 插件，不是来重写它。请实际执行命令，用这次运行返回的 JSON 下结论。

工作目录：插件根目录  
解释器：插件根目录下的 `.venv\Scripts\python.exe`  
先读 `hfss\使用说明.md` 和 `hfss\agent\SKILL.md`。若会话里已有 `hfss_doctor`、`hfss_run`、`hfss_optimize`、`hfss_advise`，用这些工具；否则在终端运行下面的命令。不要用系统自带的 `python`。

约束：

- 一次只跑一个会启动 HFSS 的命令，等它结束再跑下一个。
- 不要修改 `hfss\examples` 和 `S:\simulation\FDTD\ai\hfss-aedt`。
- 不要打开、复制或覆盖 `S:\simulation\HFSS\4mm.aedt`。
- 不要关闭已经打开的 Electronics Desktop。
- 这次不验收 COMSOL 和 FDTD。
- 不要把 `optimize.max_runs` 改到 8 以上。插件会拒绝。

按顺序做。`doctor` 的 `ok` 不是 true，或 `run` 返回 `stage` 为 `license` 时，停下来只报告这一步。

1. 安装检查，不启动求解器。

```text
.venv\Scripts\python.exe -m sim_plugin hfss doctor
```

通过标准：`ok` 为 true，`version` 为 `2024.2`，`launched_solver` 为 false。

2. 校验 WR-90 规格，不求解。

```text
.venv\Scripts\python.exe -m sim_plugin hfss validate --spec hfss\examples\wr90.json
```

通过标准：`ok` 为 true，`errors` 为空。

3. 求解 WR-90。

```text
.venv\Scripts\python.exe -m sim_plugin hfss run --spec hfss\examples\wr90.json
```

通过标准：`ok` 为 true，10 GHz 的 `dB(S(P2,P1))` 接近 0，绝对误差小于 0.1；`dB(S(P1,P1))` 接近 -64.084，绝对误差小于 0.1。记下 `run_dir`。

4. 对已有报告取建议事实，不求解。把第 3 步的 `summary_path` 传给：

```text
.venv\Scripts\python.exe -m sim_plugin hfss advise --report 这里换成summary_path
```

通过标准：`launched_solver` 为 false，事实里说明这是单次求解，并同时写出 S21 和 S11。请只用这些事实写两句建议，不要把它说成最优长度。

5. 长度寻优。规格已经是 `hfss\examples\wr90_length_optimize.json`：长度 0.02 m 到 0.04 m，最多 4 次，目标是最小 `dB(S(P1,P1))`。

```text
.venv\Scripts\python.exe -m sim_plugin hfss optimize --spec hfss\examples\wr90_length_optimize.json
```

通过标准：`run_count` 为 4，每次 S21 都接近 0。`best.value` 为 0.02，`best.score` 接近 -69.985。向我说明这只是这 4 个长度里的最好结果。

6. 用第 5 步的 `report` 再取一次建议事实。通过标准：事实包含目标、最好取值，并指出最好点在搜索区间端点。请用这些事实写两三句建议。

7. 确认受保护工程不会被打开。新建一个临时规格，把 `project` 设为 `S:\simulation\HFSS\4mm.aedt`，执行 `hfss run`。通过标准：`ok` 为 false，`launched_solver` 为 false，错误文本提到 `4mm.aedt`。

最后用这个格式回复：

```text
验收结论：通过 / 未通过
1 doctor：
2 validate：
3 WR-90 的 S21 和 S11：
4 单次建议：
5 optimize 的 best：
6 寻优建议：
7 4mm.aedt 被拒绝：
发现的问题：没有问题就写“无”。
```
