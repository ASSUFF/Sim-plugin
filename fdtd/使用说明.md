# FDTD 使用说明

最后更新：2026-11-18

在插件根目录执行。长度用米，时间用秒。`doctor` 在这台电脑上查找 Lumerical。求解默认使用找到的安装自带的 Python。`LUMERICAL_ROOT` 指向含有 `api/python/lumapi.py` 的版本目录，`LUMERICAL_PYTHON` 可以改指定解释器。`transmission()` 存在 `data.array` 时，评分取中间那个波长样本；若同时有波长轴，则按 `metric.wavelength_m` 取最近点。

用户第一次把任务完整说出来时，先整理需求并补上波长、空间范围、边界、网格精度和仿真时间。执行 `fdtd confirm --spec 草稿.json`，它不启动 Lumerical。用户同意后，把返回的 `spec` 交给 `run`、`sweep` 或 `optimize`。没有确认时这三条不启动求解器。

已有 `.fsp` 先复制到 `fdtd/runs`，原文件不覆盖。

```text
.venv\Scripts\python.exe -m sim_plugin fdtd inspect --project 模型.fsp
.venv\Scripts\python.exe -m sim_plugin fdtd set --project 模型.fsp --spec 改动.json
```

`inspect` 打开副本并列出对象，不调用求解。`set` 把 `overrides` 写入副本。

`transmission()` 的分数略大于 1 是归一化后的数值结果，不是透射超过 100%。`sweep` 和 `optimize` 现在返回 `rows` 与 `best`，字段和 COMSOL、HFSS 相同。`best` 是其中一行。分数写在 `results` 里，参数名是 `对象.属性`。`best` 只表示已算各次里最好的，落在端点时扩大区间可能还有更好的点。报告里的 `assumptions` 是确认清单中标成 `assumed` 的项。

不启动求解器的命令：

```text
.venv\Scripts\python.exe -m sim_plugin fdtd doctor
.venv\Scripts\python.exe -m sim_plugin fdtd validate --spec fdtd\examples\smoke_2d.json
.venv\Scripts\python.exe -m sim_plugin fdtd prepare --spec fdtd\examples\smoke_2d.json
```

会启动求解器的命令：

```text
.venv\Scripts\python.exe -m sim_plugin fdtd run --spec fdtd\examples\smoke_2d.json
.venv\Scripts\python.exe -m sim_plugin fdtd sweep --spec fdtd\examples\sweep_wg_width.json
.venv\Scripts\python.exe -m sim_plugin fdtd optimize --spec 一份寻优规格.json
.venv\Scripts\python.exe -m sim_plugin fdtd advise --report fdtd\runs\某次\report.json
```

`doctor` 要找到含 `api\python\lumapi.py` 的版本目录。找不到时下一步只有一个：设置 `LUMERICAL_ROOT`。`sweep` 可以沿用一个对象的一个属性，也可以在 `sweep` 里写多参数，键是 `对象.属性`，组合不超过 8 次。超过时 `stage` 为 `spec`。求解前检查网格精度、仿真时间和波长范围，不通过时 `stage` 为 `checklist`。`optimize` 对同一个属性做最多 8 次粗到细搜索。透射用 `metric.goal` 为 `max`。`advise` 只读报告。

例子：

- `fdtd/examples/smoke_2d.json`：二维偶极子和功率监视器。
- `fdtd/examples/crossing_sin.json`：氮化硅交叉波导。2026-11-19 本机结果在 `fdtd/runs/20261119_134300_sin_crossing`：1550 nm 处右端口 T = 0.4199759615463277，下端口 T = -0.4196139481440062，绝对值都约为源功率的 42%。下端口的负号来自该监视器的 `transmission()`。
- `fdtd/examples/sweep_wg_width.json`：波导 `y span` 的单参数扫描。

结果写到 `fdtd/runs`。源工程先复制，不覆盖原 `.fsp`。
